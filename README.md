## 🧾 Project: Envirio Mbox — IoT-Based Air Pollution Monitoring System

📍 **Client Type/Location:** Industrial / Construction Site Monitoring

🛠️ **Tech Stack:**  
- Frontend: React.js  
- Backend: Python (Django)  
- Authentication: Keycloak  
- Communication Protocol: MQTT (for IoT device connectivity)  
- Data Visualization: Interactive Graphs and Reports  
- Deployment: Hosted at [https://mbox-mlp.rdprojects.tech/](https://mbox-mlp.rdprojects.tech/)

🎯 **Overview:**  
Envirio Mbox is an IoT-driven environmental monitoring solution designed for construction sites to measure air pollution and various environmental parameters in real time. Multiple sensors integrated within the Mbox device capture data such as particulate matter, gas concentrations, and other pollution metrics. The data is transmitted via MQTT protocol to the backend, where it is processed and visualized through a secure React-based web interface.

🔧 **My Contribution:**  
- Developed the frontend using React.js, focusing on responsive and intuitive UI for real-time data visualization  
- Integrated Keycloak for robust authentication and user management  
- Collaborated with backend team working in Django to ensure seamless API communication and data handling  
- Implemented real-time updates and interactive charts to display sensor data and generate comprehensive reports  
- Assisted in integrating MQTT communication protocol between devices and backend servers
